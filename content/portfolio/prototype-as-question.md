**Working idea.** A prototype should answer one decision question before it imitates a finished product.

That shift changes what to make, what to leave out, and how to judge the result. A prototype is useful when it makes uncertainty visible enough to discuss.

## Start with the decision

Write the decision in one sentence. Then name the uncertainty that blocks it.

For example, a team might be unsure whether a support form should begin with a question or a category list. A paper sketch can test the sequence. It cannot test response time, account access, or keyboard behavior.

Name those limits before the test. This keeps a quick sketch from answering a question it cannot reach.

## Match detail to uncertainty

Use the least costly material that can expose the risk.

- Use a rough outline to compare order, labels, or missing steps.
- Use linked screens to test navigation and task flow.
- Use working code when timing, device behavior, or data changes the answer.
- Use a service rehearsal when people, policies, or handoffs create the risk.

A polished surface can distract from an unresolved question. Add detail only when that detail changes what a reader can notice.

## Give the test a decision

Ask a reader to complete a task without explaining each step. Watch where they pause, what they expect, and what they cannot find.

Before the session, record four things:

1. The question that the prototype must answer.
2. The smallest artifact that can make the question concrete.
3. The behavior or response that you will observe.
4. The result that would change the next decision.

This note gives the test a purpose. It also makes a negative result useful.

## Use the result carefully

One test can show where an idea needs work. It cannot prove that every reader will respond the same way.

Keep the observation separate from its interpretation. “Three readers missed the second link” describes an observation. “The page has too many choices” is one possible interpretation.

The value of a prototype comes from the quality of the question and the next decision. The artifact can stay small when both are clear.
